# PumpLog 💪

筋トレ記録を可視化するWebアプリです。  
トレーニングメニューを作成し、重量・回数・セット数を記録できます。

## Features

- トレーニングメニュー作成
- 種目ごとの重量・回数・セット数記録
- 今日のトレーニング表示
- 過去の記録を日付ごとに表示
- 7日間の部位別分析
- 筋肉マップによるトレーニング部位の可視化
- 種目ごとのPR表示
- 次に鍛えるべき部位の提案

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- localStorage

## Purpose

筋トレの記録をただ残すだけでなく、  
「どの部位を鍛えたか」「どの部位が不足しているか」を可視化することで、  
バランスの良いトレーニングをサポートすることを目的としています。
